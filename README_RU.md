# ПОСЛЕДНИЙ ОЧАГ — первая версия Telegram-игры

Это стартовый MVP Telegram-бота на Python.

## Что уже работает
- регистрация игрока через `/start`;
- личная база и центральная печь;
- стартовые ресурсы;
- пассивное производство ресурсов (начисляется при следующем входе, максимум за 12 часов);
- улучшение печи за ресурсы;
- рейтинг игроков;
- кнопочное меню Telegram.

## Что пока является заготовкой
- альянсы;
- бои и экспедиции;
- герои;
- реальные платежи и донат;
- защита от атак и полноценный баланс.

## Запуск

Нужен Python 3.10 или новее.

1. Создайте бота через `@BotFather` в Telegram командой `/newbot`.
2. Скопируйте выданный токен.
3. Скопируйте `.env.example` в файл `.env`.
4. Вставьте токен в `BOT_TOKEN=...`.
5. Установите зависимости:

   `python -m pip install -r requirements.txt`

6. Запустите:

   `python bot.py`

Пока программа работает на компьютере/сервере, бот отвечает игрокам. Для постоянной работы понадобится VPS или другой хостинг.

## Важно
Не публикуйте токен бота и не отправляйте его в общие чаты. Если токен случайно раскрыт, перевыпустите его через BotFather.
